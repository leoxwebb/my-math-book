## 1. 序章的定位与任务

序章不是某个数学领域的章节，而是**整本书的"图例"（legend）**：读者在这里拿到地图的坐标系、
符号约定和使用说明。它要完成四件事：

1. **回答"数学是什么"**——给出一个可操作的回答，而非哲学讨论。
2. **展开整张地图**——让读者第一次看见全书十个部分如何覆盖现代数学。
3. **示范数学语言**——用最小的例子展示定义、公理、定理、证明长什么样。
4. **教读者用这本书**——三层深度、章节模板、阅读路线、与 AI 协作的基本姿势。

**写作基调**：不证明、不计算；每个概念配一个最小的、可感知的例子。
**篇幅预算**：约 8000–12000 字（速览层约 1500 字）。

## 2. 章节结构（节级框架）

### 0.0 开篇：两个问题

- 引子：拿一个现实问题（如"推荐系统为什么给我推这个？"或"地图导航如何找最短路径？"），
  追问它背后藏着哪几片数学 → 引出"没有地图就不知道问题属于哪里"。
- 本章要回答的两个问题：**数学研究什么？** 以及 **这本书怎么用？**

### 0.1 数学研究的六类对象

对应大纲条目一。核心是一张"六类对象总表"，每类对象给出：直觉描述 → 起源问题 →
代表分支 → 代表符号 → 对应本书的部分。

| 对象 | 直觉 | 起源问题举例 | 代表分支 | 代表符号 | 对应部分 |
|------|------|--------------|----------|----------|----------|
| **数** | 可以计数与度量的东西 | 有多少？√2 是数吗？ | 数论、数系 | `ℕ ℤ ℚ ℝ ℂ  a ≡ b (mod n)` | 第一、二部分 |
| **形** | 空间、形状与位置 | 平行线会相交吗？ | 几何、拓扑 | `ℝⁿ  π₁(X)  g_{ij}` | 第五部分 |
| **结构** | 带运算或关系的集合 | 对称如何描述？ | 代数 | `(G, ·)  V  R[x]` | 第三部分 |
| **变化** | 随时间或位置变动的量 | 瞬时速度是什么？ | 分析、微分方程 | `lim  f'(x)  ∫  uₜ = Δu` | 第四部分 |
| **不确定性** | 无法完全预言的现象 | 赌局怎么分赌金？ | 概率、统计、信息论 | `P(A | B)  𝔼[X]  H(X)` | 第七部分 |
| **计算** | 可按规则机械执行的过程 | 什么问题可解？多快？ | 可计算性、复杂性 | `O(·)  P  NP  λx. M` | 第六、八、九部分 |

- 写作要点：强调六类对象**互相交织**（如"随机过程 = 不确定性 × 变化"、
  "图 = 结构 × 形"），为后文"交汇"埋伏笔。

### 0.2 数学地图：这片大陆的行政区划

对应大纲条目二。

- **纯数学与应用数学**：不是两块领土，而是同一片大陆的两种旅行方式
  （举例：数论→RSA，黎曼几何→广义相对论/GPS）。
- **MSC（国际数学分类）简介**：只需知道它存在、约 60 多个一级分类、
  论文和 arXiv 用它定位；给 2–3 个分类号示例（如 11 数论、53 微分几何、68 计算机科学）。
- **本书十个部分与地图的对应**：复用大纲末尾的 Mermaid 领域关系图（简化版），
  让读者第一次"看见"全书结构。

### 0.3 三大主干与它们的交汇

对应大纲条目三。

- **三大主干**：
  - 代数——研究运算与结构（离散的、精确的）
  - 分析——研究极限与变化（连续的、逼近的）
  - 几何/拓扑——研究空间与形状（直观的、整体的）
- **交汇处往往是最深刻的数学**（每个交汇给一句话 + 指向章节）：
  - 代数 × 分析 → 解析数论（第 5 章）、李群（第 11 章）、泛函分析（第 17 章）
  - 代数 × 几何 → 代数几何（第 26 章）、代数拓扑（第 24 章）
  - 分析 × 几何 → 微分几何（第 25 章）
  - 三者汇流 → 朗兰兹纲领（第 43 章）
- 可视化：三圆维恩图或三角形交汇图。

### 0.4 数学的语言：定义、公理、定理、证明

对应大纲条目四。这一节是全书"读符号"训练的起点。

- **四种基本语句**的角色（用"游戏"类比：公理=规则，定义=命名棋子，
  定理=必然局面，证明=复盘推演）：
  - 定义（definition）——精确地命名
  - 公理（axiom）——不加证明的出发点
  - 定理/引理/命题/推论（theorem / lemma / proposition / corollary）——层级与惯例
  - 证明（proof）——从公理与已知到结论的推理链，`∎` 的含义
- **最小示范**：完整走一遍"定义偶数 → 陈述'偶数+偶数=偶数' → 三行证明"，
  让读者在序章就见过一个真正的证明。
- **精确性与抽象性**：
  - 精确性：日常语言的"或/任意/存在"vs 数学的 `∨ ∀ ∃`；一个歧义句的改写练习。
  - 抽象性：抽象 = 删去无关细节以便复用（同一个群既是魔方又是加密算法）。
- **符号是压缩语言**：以 `e^{iπ} + 1 = 0` 或 `∀ε>0 ∃δ>0 …` 为例，
  演示"逐符号读出一个式子"的方法——这是全书每章"自测"的原型。

### 0.5 一副统一的眼镜：观察框架

把大纲 0.6 的观察框架正式介绍给读者（它将出现在每一章）：

> **对象** → **结构** → **保持结构的映射** → **不变量** → **分类**

- 用一个非数学例子预热（如：对象=乐曲，结构=调性，映射=移调，不变量=旋律轮廓）。
- 再用一个数学例子落地（如：三角形 / 全等变换 / 边长与角度 / 按边角分类）。
- 说明：以后每进入新领域，先问这五个问题，就不会迷路。

### 0.7 动手与自测（遵循统一模板第 9、10 段）

- **动手**：
  - 一段代码（只依赖标准库）：用 Python 分别"碰一下"六类对象
    （素数筛选、立方体欧拉公式、置换复合不交换、差商求导、抛硬币模拟、考拉兹迭代）。
  - 一次 AI 对话练习：把一句模糊需求（"帮我找出数据里的异常"）翻译成数学化提问，
    对比模糊提问与精确提问得到的回答差异。
- **自测**：读懂 3 个式子（难度递进，答案在延伸层）：
  1. `A ∪ B = {x | x ∈ A ∨ x ∈ B}` ——集合与逻辑符号
  2. `∀n ∈ ℕ ∃p ∈ ℕ (p > n ∧ p 是素数)` ——量词的嵌套读法
  3. `¬∃q ∈ ℚ (q² = 2)` ——否定与数系符号
  - 附加题：交换第 2 题的量词顺序，体会真命题变为假命题
  - （`e^{iπ} + 1 = 0` 与 `∀ε > 0 ∃δ > 0 …` 已在 0.4 节作为读式示范，不再重复作为自测）
