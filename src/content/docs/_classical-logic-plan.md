# 第 1 章写作框架：经典逻辑——命题是真值

依据：[全书大纲](../../../OUTLINE.md) 的 0.1–0.7、第一部分演进表和第 1 章提要。正文为 [classical-logic.mdx](./classical-logic.mdx)，本规划不发布到站点。

## 一、定位、主线与阅读目标

本章是序章之后的第一个领域章，采用十段模板，不另写第一部分导言，也不提前展开集合论、非经典逻辑和类型论。

**主线**：推理起初被看成主谓句之间的模式；为了处理复杂的复合条件，把命题按真假进行运算；为了处理关系和“每个……都有……”，引入谓词与量词；为了检查任意长的论证，把证明变成可核查的符号操作，并把可证与模型中的真分开；完备性连接二者，不完备性则划清这座桥的适用边界。

两条贯穿例子：

- **门禁规则**：“刷卡成功则开门”，用来讲实质蕴含、逆否、常见谬误、反例、SAT/SMT 和规约的局限。
- **数的大小**：“每个数都有比它大的数”，用来讲多重量词、论域、模型和量词换序。

读后应能：

1. 区分命题、谓词、闭句，以及真值与是否已经知道答案。
2. 读懂五种联结词和真值表，说明为什么假前件使实质蕴含为真。
3. 读懂量词的范围和顺序，写出含量词命题的否定。
4. 区分推理有效与前提真实，辨认肯定后件、否定前件。
5. 说出四种证明方法的用途，知道归纳法要有对应的数系与归纳原理。
6. 区分公式、推理规则、公理、形式证明，以及语法与语义。
7. 读懂 `⊢`、`⊨`，准确转述完备性与不完备性的不同对象和前提。
8. 把简单工程规则转成公式，并用反例检查 AI 的推理。

### 十张概念卡

每卡固定四项：直觉、定义的读法、例子或边界、在演进线上修补了什么。

1. 命题与真值：固定解释后非真即假；未知不等于第三个值；命题不字面等于两个真值之一。
2. 联结词与真值表：完整列出否定、合取、析取、蕴含、等价；析取默认包含两者都真。
3. 实质蕴含：等价于 `¬P∨Q`；唯一反例为 P 真 Q 假；不表示因果；充分必要条件及逆否。
4. 谓词与量词：自由/约束变量、闭句、论域、次序、否定、唯一存在、空满足。
5. 推理规则：肯定前件、全称实例化、存在量词的见证限制和全称推广的任意性。
6. 证明方法：直接、反证、归纳、构造；逆否与反证区分；有限穷举的边界。
7. 公理系统：语言、逻辑规则与非逻辑公理；T、Γ、φ 等元记号。
8. 语法与语义：赋值、模型、可满足、有效、逻辑后承、可证的层级区别。
9. 一致性：无矛盾可导出；经典逻辑爆炸原理；不等于公理确实描述现实。
10. 完备性：演算的语义完备性与理论的否定完备性；与可靠性、可判定性分开。

## 六、必须守住的准确性边界

1. “命题是真值”是本章的语义视角，不是说全世界只有两个命题；语句仍有结构与不同意义。
2. 二值性本身并不唯一强制出蕴含真值表；须说明选择“排除 P 真 Q 假”的条件含义和真值函数要求。
3. 未知、没有证明、为假是三个不同概念。
4. 现代命题逻辑不全出于亚里士多德，古代斯多亚学派也研究过命题联结；这里只选主线。
5. 三段论的限制针对传统词项框架；不能说它没有任何量化思想。
6. 弗雷格不是直接写出了今天的 `∀`、`∃`；布尔也没有直接给出现代真值表。
7. 演进按概念组织，不暗示塔斯基 1933 年的论文先于哥德尔 1929/1930 年的完备性工作。
8. 模型中为真、所有模型中为真、T 的所有模型中为真不可混用。
9. Γ 中可以有无限多个前提，但每份形式证明有限；不得说完备性承诺一个终止的判定算法。
10. 第一不完备定理采用含罗斯尔加强的现代版本；若只以一致性为条件，不把原始哥德尔句及其否定的不可证性混为一谈。
11. 第二不完备定理限于足够强的系统和标准一致性表达及可证性条件，不声称任何系统都不能讨论自身。
12. 一阶逻辑完备不等于算术理论完备；标准自然数结构不等于所有满足同一组一阶公理的结构。
13. 不完备性不否定经典二值语义，不直接推出直觉主义或类型论，不证明“人胜过机器”。
14. 归纳法需要自然数背景和归纳原理，构造法不等同于只能写出十进制数值。
15. 程序规约的部分正确性不包含终止；SAT 的有限可判定性不等于高效；SMT 可返回 unknown。
16. SQL 关系演算的数学根基与 SQL 的重复行、NULL 等具体语义区别处理。
